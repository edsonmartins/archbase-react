## Uso Básico

`ArchbaseMentionInput` é um componente de entrada de texto com suporte a menções (@usuários, #tags, etc.) e integração com DataSource. Construído sobre o `Mentions` do Mantine (a partir do `@mantine/core` 9.8).

<Demo data={demos.mentionInputUsage} />

## Configuração de Menções

```tsx
const mentions = [
  {
    trigger: '@',
    data: [
      { id: '1', display: 'João Silva' },
      { id: '2', display: 'Maria Santos' },
    ],
  },
  {
    trigger: '#',
    data: [
      { id: 'bug', display: 'bug' },
      { id: 'feature', display: 'feature' },
      { id: 'melhoria', display: 'melhoria' },
    ],
  },
];

<ArchbaseMentionInput
  label="Comentário"
  mentions={mentions}
  placeholder="Use @ para mencionar e # para tags..."
/>
```

## Formato do Valor

O valor gravado no DataSource é o texto com o *markup* das menções. O padrão é `[__display__](__id__)`, **sem** o caractere gatilho:

```text
Olá [Maria Santos](2), pode revisar?
```

Esse é o mesmo formato das versões anteriores (baseadas em `react-mentions`) — textos já gravados continuam sendo reconhecidos. Note que é diferente do padrão do `Mentions` do Mantine (`@[__display__](__id__)`). Para outro formato, informe `markup` por gatilho:

```tsx
{ trigger: '#', data: tags, markup: '#{__id__}' }
```

Para extrair as menções de um valor (ex.: ao salvar), use `getMentions` do `@mantine/core` passando o mesmo `markup`:

```tsx
import { getMentions } from '@mantine/core';

getMentions(valor, [{ trigger: '@', markup: '[__display__](__id__)' }]);
```

## Busca Assíncrona

`data` aceita uma função. As duas assinaturas funcionam:

```tsx
// Retornando Promise (estilo Mantine)
{ trigger: '@', data: async (search) => api.buscarUsuarios(search) }

// Com callback (estilo react-mentions, mantido por compatibilidade)
{ trigger: '@', data: (search, callback) => api.buscarUsuarios(search).then(callback) }
```

## Linha Única

```tsx
// Multilinha (padrão)
<ArchbaseMentionInput
  label="Comentário"
  mentions={mentions}
/>

// Linha única
<ArchbaseMentionInput
  label="Buscar"
  mentions={mentions}
  singleLine
/>
```

## Estados

```tsx
// Desabilitado
<ArchbaseMentionInput label="Comentário" disabled mentions={mentions} />

// Somente leitura
<ArchbaseMentionInput label="Comentário" readOnly value="Olá @João!" mentions={mentions} />

// Com erro
<ArchbaseMentionInput label="Comentário" error="Campo obrigatório" mentions={mentions} />
```

## Com DataSource

```tsx
<ArchbaseMentionInput
  dataSource={dataSource}
  dataField="comentario"
  label="Comentário"
  mentions={mentions}
/>
```

## Props

| Prop | Tipo | Padrão | Descrição |
|------|------|--------|-----------|
| value | `string` | `''` | Texto com menções |
| onChangeValue | `(value: string, event) => void` | - | Callback ao alterar valor. `event.target.value` é o valor; `event.payload` traz o payload completo do Mantine (`plainTextValue`, `mentions`, …) |
| label | `string` | - | Rótulo do campo |
| mentions | `ArchbaseMentionConfig[]` | `[]` | Configuração de menções (trigger + data) |
| singleLine | `boolean` | `false` | Modo linha única |
| allowSuggestionsAboveCursor | `boolean` | `true` | Permite abrir as sugestões acima do cursor quando falta espaço abaixo |
| placeholder | `string` | - | Texto placeholder |
| disabled | `boolean` | `false` | Desabilitar o campo |
| readOnly | `boolean` | `false` | Somente leitura |
| error | `string` | - | Mensagem de erro |
| dataSource | `DataSource` | - | DataSource para binding |
| dataField | `string` | - | Campo do DataSource |
