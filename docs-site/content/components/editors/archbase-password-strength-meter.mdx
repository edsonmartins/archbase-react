## ArchbasePasswordStrengthMeter

Medidor de força de senha: exibe uma barra de progresso e a lista de critérios
atendidos, avaliando o valor contra uma política de senha forte.

É o mesmo feedback que o `ArchbasePasswordEdit` mostra quando recebe a prop
`passwordPolicy`. Use este componente diretamente quando precisar do medidor ao
lado de um input próprio, ou em um layout diferente do padrão.

### Uso Básico

```tsx
import { useState } from 'react';
import { PasswordInput } from '@mantine/core';
import { ArchbasePasswordStrengthMeter } from '@archbase/components';

function CadastroSenha() {
  const [senha, setSenha] = useState('');

  return (
    <>
      <PasswordInput
        label="Senha"
        value={senha}
        onChange={(event) => setSenha(event.currentTarget.value)}
      />
      <ArchbasePasswordStrengthMeter value={senha} />
    </>
  );
}
```

Sem a prop `policy` o componente aplica a política padrão do Archbase:
8 caracteres, ao menos uma letra minúscula, uma maiúscula, um número, um símbolo
e nenhum espaço em branco.

### Definindo os critérios

```tsx
<ArchbasePasswordStrengthMeter
  value={senha}
  policy={{
    minLength: 12,
    minUppercase: 1,
    minNumbers: 1,
    forbidSequential: 4,
    blocklist: ['archbase', usuario.email?.split('@')[0]]
  }}
/>
```

A lista completa de critérios está documentada em
[ArchbasePasswordEdit](/components/editors/text-inputs).

### Somente o que falta

Para uma apresentação mais discreta, exiba apenas os critérios ainda não
atendidos e esconda a barra:

```tsx
<ArchbasePasswordStrengthMeter
  value={senha}
  onlyUnmetRequirements
  showStrengthBar={false}
/>
```

### Controlando o botão de salvar

```tsx
const [senha, setSenha] = useState('');
const [senhaValida, setSenhaValida] = useState(false);

<>
  <PasswordInput value={senha} onChange={(e) => setSenha(e.currentTarget.value)} />
  <ArchbasePasswordStrengthMeter
    value={senha}
    onValidationChange={(result) => setSenhaValida(result.valid)}
  />
  <Button disabled={!senhaValida} onClick={salvar}>Salvar</Button>
</>
```

`onValidationChange` só dispara quando o resultado muda de fato — não a cada
tecla — então é seguro usá-lo para atualizar estado do componente pai.

### Props

| Prop | Tipo | Padrão | Descrição |
|------|------|--------|-----------|
| `value` | `string` | `''` | Senha a ser avaliada |
| `policy` | `ArchbasePasswordPolicy \| boolean` | `true` | Critérios exigidos. `true` aplica a política padrão |
| `showStrengthBar` | `boolean` | `true` | Exibe a barra de força |
| `showRequirements` | `boolean` | `true` | Exibe a lista de critérios |
| `onlyUnmetRequirements` | `boolean` | `false` | Exibe apenas os critérios não atendidos |
| `size` | `MantineSize` | `'xs'` | Tamanho do texto dos critérios |
| `onValidationChange` | `(result: ArchbasePasswordValidationResult) => void` | - | Disparado quando o resultado da validação muda |
| `style` | `CSSProperties` | - | Estilo do container |

### Classificação da força

| Força | Significado |
|-------|-------------|
| `empty` | Campo vazio |
| `weak` | Pontuação baixa |
| `fair` | Pontuação intermediária |
| `good` | Atende à política, com boa pontuação |
| `strong` | Atende à política, com pontuação alta |

Uma senha que viola a política nunca é classificada como `good` ou `strong`, por
mais longa que seja — caso contrário o medidor premiaria o comprimento e
ignoraria a regra.

**Atenção:** esta é uma validação de entrada, executada no navegador e portanto
contornável. Aplique a mesma política também no backend.
